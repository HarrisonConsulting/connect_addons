Calls become tickets, tickets link back.

Connect Helpdesk bridges Twilio inbound calls with the helpdesk workflow. Agents create tickets from the softphone, search existing tickets by customer phone, and track all call history linked to each support case.

See how it works Talk to us →

Why

Support teams use helpdesk for ticket tracking and Twilio for voice calls, but the systems live apart. Without a bridge, agents manually create tickets after calls end, losing the live context. History fragments across two systems, and follow-up calls require searching by phone number again.

How it works

  1. Incoming call links to partner
    When a call lands, Connect matches the caller phone to a res.partner and exposes it in the softphone UI.
  2. Agent searches partner tickets
    Right from the call panel, agents query open and closed tickets for that customer with a single tap.
  3. Create or link ticket on hang-up
    Via ElevenLabs agent tools, the AI (or a human) creates a new ticket or tags an existing one with call ID and duration before the call closes.
  4. Full call history on ticket
    Each helpdesk.ticket shows all linked calls in a One2many field with duration, direction, recording, and timestamp.
  5. Settings control routing and team assignment
    Configure default helpdesk team, ticket name prefix, and field mapping so tickets land in the right queue on creation.

What's in the box

Ticket model inheritance

Extends helpdesk.ticket with connect_calls One2many and phone_normalized for call matching.

Call model link

Adds ticket field to connect.call so incoming and outgoing calls can be logged against support cases.

Settings and UI views

Company-level configuration for default helpdesk team, ticket naming, and field defaults. List and form views for call-ticket linkage.

Compatibility

Odoo 19.0

Depends on helpdesk and connect. Note: helpdesk is an Enterprise module; use connect_helpdesk requires an active Odoo Enterprise subscription.

Field note — for support teams only

This module assumes helpdesk is installed. If you lack an Odoo Enterprise subscription or don't use the helpdesk module, this bridge will not work. Ticket creation via ElevenLabs agent tools requires the connect_elevenlabs_helpdesk extension.
