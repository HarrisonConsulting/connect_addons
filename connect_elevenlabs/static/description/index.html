Why

ElevenLabs runs the agent. Twilio carries the audio. Odoo holds the customer, the calendar, and the history. Stitching the three together by hand means juggling agent IDs, knowledge-base IDs, webhook signatures, and conversation summaries. This module makes the Odoo record the source of truth: edits sync up, conversations sync back, transcripts and summaries land on the call record.

How it works

  1. Author an agent in Odoo
    Pick a voice, choose an LLM (GPT, Claude, Gemini, or ElevenLabs-hosted), set first message, stability, speed, and turn timing.
  2. Save syncs to ElevenLabs
    Create mirrors to the platform API; write updates push only the changed fields; delete removes the agent and its knowledge base.
  3. Attach a Twilio extension
    The agent gets a Connect extension; inbound calls render a TwiML <Stream> to your media-bridge service for the live conversation.
  4. Tools call back into Odoo
    Calendar slots, event creation, meeting lookup, and agent transfer are HTTP routes guarded by a shared token in the x-elevenlabs-agent-token header.
  5. Post-call writes summary and audio
    An HMAC-signed post-call webhook lands the transcript, summary, conversation ID, and full recording onto the matching connect.call.

What's in the box

Bidirectional agent sync

Edit in Odoo, push to ElevenLabs; or pull a manual sync to import existing agents and update their fields by agent_uid.

Prompt version history

Every prompt edit snapshots a numbered version on the agent; the active version is selectable so you can roll forward or back.

Custom and built-in tools

Define webhook tools with parameters and timeouts; system tools cover voicemail detection, DTMF tones, and agent-to-agent transfer.

Calendar tooling, authenticated

Four routes — free slots, create event, list meetings, remove meeting — accept timezone strings or offsets, all behind a shared token check.

Knowledge base per agent

Editing the knowledge-base text on the agent creates, updates, or deletes the corresponding ElevenLabs document and keeps the ID in sync.

Phone-number registration

A separate model registers Twilio caller-ID numbers with ElevenLabs for outbound agent calls, with status, error, and last-sync tracking.

Compatibility

Field note — sync errors are facts, not failures

Agents have a Sync Status field that goes red when the platform call fails. We do not retry blindly; the last error is on the record so the operator can see exactly what ElevenLabs complained about. Fix the field, save again, status returns to synced. Boring is the point.
