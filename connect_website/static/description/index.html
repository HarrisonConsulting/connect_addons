ODOO MODULE · CONNECT INTEGRATION

A talk button for your website visitors.

Drop a snippet on any page of your Odoo website. A visitor clicks it and a real call is placed from their browser to a Connect extension over Twilio — no plug-in, no dial pad, no phone number to copy.

Why

Contact forms are slow and chat widgets are noisy. Connect Website gives the visitor a single button labelled Let's Talk that opens a WebRTC voice channel to whichever Connect extension you nominate. Inbound calls back to the same browser session also work — the visitor's anonymous identity is remembered, so an agent in Odoo can dial the page back.

How it works

  1. Edit a page, drag the snippet
    Under the website editor's Content snippets you'll find Connect Button. Drop it where you want the call point to live.
  2. Point it at an extension
    In Connect Settings, the new Website tab takes a connect.exten and a connect.domain — the call routes through the domain to the extension's TwiML.
  3. The browser becomes a softphone
    A public route mints a short-lived Twilio access token with a Voice grant; the page loads the Twilio Voice SDK and registers the visitor as a WebRTC client.
  4. Calls land as records
    Inbound and outbound legs each create a connect.call with caller resolution against partners — the call shows up in the Phone app like any other.
  5. Tokens refresh, identity persists
    Access tokens live one hour and renew on tokenWillExpire. The visitor's identity is an 8-digit value cached in localStorage so return visits stay reachable.

What's in the box

Drag-and-drop snippet

One s_connect_button snippet registered under Content. SCSS, OWL template, and the Twilio Voice SDK ship with it.

Public token endpoint

Two jsonrpc routes: one returns whether the button is enabled and which number to dial, the other mints a 3600s Twilio access token with a Voice grant.

Settings tab

A Website page on Connect Settings ties the button to one extension and one domain. Disable kills the snippet's RPC without touching the page.

Inbound dial-back

The domain router recognizes 8-digit identities and dials a website visitor as a Twilio <Client>, with caller-ID from the agent's extension.

Partner resolution

Inbound calls match by phone number; logged-in Odoo users pass their UserId and the call links to their partner without a second lookup.

Three-state button

Idle, ringing (incoming), and in-call states are wired with CSS classes — no animation library, just ring and red on the body element.

Compatibility

Odoo 19.0 connect website

Depends on website and connect. Requires a configured Twilio account (API key, API secret, TwiML application on the chosen domain). The visitor's browser needs WebRTC and microphone permission.

Field note — one button, one extension

This module ships exactly one snippet pointed at exactly one extension. No tenant selectors, no per-page routing, no business-hours fallback in the widget itself — those belong on the callflow the extension already owns. If you need different buttons on different pages, you're past what this addon does.
